# Brand fonts

The three typefaces named in `docs/brand.md`, vendored so `scripts/build_carousel.py`
renders identically on any machine without a network fetch.

| File | Family | Used for |
|---|---|---|
| `Syne-ExtraBold.ttf`, `Syne-Bold.ttf` | Syne | Slide titles |
| `Inter-Regular.ttf`, `Inter-SemiBold.ttf` | Inter | Body copy |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf` | JetBrains Mono | File paths, commands, slide numbers |

All three are licensed under the **SIL Open Font License 1.1**, which permits
redistribution in this form. Retrieved from Google Fonts.

- Syne: https://fonts.google.com/specimen/Syne
- Inter: https://fonts.google.com/specimen/Inter
- JetBrains Mono: https://fonts.google.com/specimen/JetBrains+Mono
